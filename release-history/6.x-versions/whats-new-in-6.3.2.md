# What's New in 6.3.2

### Updated Dependencies

We've updated to the Undertow and Log4J Libraries in this release, which include security fixes.

- Runwar legacy uses Undertow 2.2.39.Final now
- Runwar Jakarta uses Undertow 2.3.21.Final now
- Both runwars use Log4j 2.25.3 now
